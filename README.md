# agentd (provisional name)

Agent runner: persistent workspaces and bounded JavaScript execution for agents.
Sandbox on [celld](https://celld.dev), durable state in PostgreSQL, bytes in a bucket.
Flue integration first; Eve or Pi later via adapters.

Status: documentation only. No code yet.
